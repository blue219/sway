## Repository structure
- Using animal-island-ui style when modify front-end code
- Follow the rules when generate movements pngs:
    - Canvas: exactly 1024 × 1536 px, portrait.
    - Subject: one full-body older adult demonstrating [ACTION].
    - Composition: centered, complete head, hands, and feet visible; no cropping.
    - Scale: the visible person should occupy about 85% of the canvas height,
    - with 80–120 px space above the head and 100–150 px below the feet.
    - Keep at least 60 px transparent margin on the left and right.
    - Style: match the existing soft, friendly exercise illustrations.
    - No text, no ground, no props, no border, no background, no cast shadow.
    - Export as a PNG with a fully transparent background.
